## Loose

#### **13 October 2026**

* Prompt
  *   _there is, what i'm imagining could be, a relatively largely feature that i'd like to prototype._

      \
      _i'm going to describe that feature roughly below._ \
      \
      _before implementing anything, i'd like you to try to mock up the experience in a design file so that i can get a feel for what you'd be planning to implement._

      \
      _ok, now onto the feature..._

      \
      _to help facilitate conversations between people, i'd like to experiment with a feature that would enable people to set a ping as public. these "public" pings would be browsable in a different mode of the app that would function as the current app does, but would instead appear in a different color so as to distinguish it from your private pings._ \
      \
      _from there, you could hand over your phone to someone else (and vice versa) and they could browse your pings themselves._ \
      \
      _ideally, doing so would help people to find things that resonate with one another and with it, identify conversations/topics to explore together._

      \
      _the action for making a ping public would replace the "hide" button that is currently displayed beneath every ping within the "focus " view. i think this button should only become available after some yet-to-be defined after the ping was originally captured has elapsed. maybe 24 hours? the thinking here being that people ought to be somewhat intentional about the pings people mark as public. i also think a mechanic of this sort could inspire people to revisit rather than have capture and "share" (i'd like to come up with a different verb...maybe "transmit"?) moments be one-in-the-same._

      \
      _similar to how "hide" / "show" currently works, a ping could be made removed from the "public" view at any point._

      \
      _now, with regard to this "public" mode, i'm thinking that, for now, we could add a toggle in settings. if/when i come to think the feature is working, we can figure out a place so that it's easier for people to reach and discover._<br>

      _also, i'd like to add some kind of protection (maybe a simple 4-digit password) that would someone would be required to enter before toggling back from "public" into "private" mode (i want someone who is handing their phone over to feel confident someone isn't accidentally going to access pings they didn't want/mean to be visible)._<br>

      _there are a set of questions that remain open in my mind about what (if any) actions someone can take on a ping within public mode. to start, it could be interesting if all of the same actions work and maybe the metadata that would be associated with re-pings and replies would be enough for someone to remember who a particularly interaction was from based on the timestamp associated with it (e.g. "ah, i met up with lucy on september 8, 2026...this reply must be from her")_
